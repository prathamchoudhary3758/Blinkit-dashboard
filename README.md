# Blinkit Sales Analysis Dashboard | Power BI

## Project Overview
Developed an interactive Power BI dashboard to analyze Blinkit's sales performance across different outlet types, outlet sizes, locations, and product categories. The dashboard transforms sales data into meaningful visual insights, helping users understand revenue distribution, product performance, and outlet-level trends.

## Key Features
- **Sales KPI Tracking:** Displays total sales, average sales, number of items, and average ratings.
- **Outlet Performance Analysis:** Compares sales trends across outlet establishment years and outlet types.
- **Product Category Analysis:** Identifies top-performing and lower-performing item categories based on total sales.
- **Fat Content Analysis:** Visualizes sales distribution by low-fat and regular-fat product categories.
- **Outlet Size and Location Analysis:** Compares sales contributions across outlet sizes and location tiers.
- **Interactive Filters:** Enables dynamic analysis by outlet location type, outlet size, and item type.
- **Data Visualization:** Uses KPI cards, line charts, donut charts, bar charts, and a comparative summary table.

## Tools & Technologies
- Microsoft Power BI Desktop
- Power Query for data preparation, if used
- DAX for measures and KPIs, if used
- Data visualization and exploratory data analysis

## Business Value
The dashboard provides a consolidated view of sales performance and helps identify high-performing product categories, compare outlet segments, and explore trends that can support data-driven retail decisions.
